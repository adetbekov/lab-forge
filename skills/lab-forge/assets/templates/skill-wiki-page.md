# wiki-page

{{wiki_access_note: e.g. "The agent cannot reach the wiki; produce markdown the user pastes."}}

Structure (drop sections that do not apply):
1. **TL;DR** - 2-3 sentences: what was done and the result with baseline.
2. **Context** - the problem and why it mattered.
3. **Approach** - the steps, with one diagram if it saves words.
4. **Results** - table `baseline -> new`, how it was measured.
5. **How to use / run** - real commands and paths.
6. **Limitations and next steps**.

Keep it short: a reader should get the point from section 1 alone.
